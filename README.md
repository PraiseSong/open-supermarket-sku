# open-supermarket-sku

面向便利店、批发选品和进货工具的商品资料查询。

- 用**商品名称**查询：商品条码、规格等
- 用**商品条码**反查：商品详情（名称、规格等）

本仓库提供约 **2000 条开源样本**，方便程序员和小团队对接联调。完整库与持续更新通过 **API 授权**使用。

商品库**不定期更新**。针对新上市的日用快销品，**可做到一周内更新**。

## 为什么先看样本

自己维护一份静态 JSON 会过时。样本用来验证「按名称查条码 / 按条码查详情」是否够接进你的进货或店长工具；上线后再换成授权 API，才能跟上新品。进货渠道价仅在授权 API 中提供，开源样本不包含。

## 样本字段

| 字段 | 说明 |
|------|------|
| `name` | 商品名称 |
| `barcode` | 商品条码 |
| `spec` | 规格（数组，可能有多种包装） |
| `category` | 分类（便于浏览样本） |

数据文件：[`data/products.sample.jsonl`](data/products.sample.jsonl)（一行一条 JSON）  
预览 8 条：[`data/products.preview.json`](data/products.preview.json)

样本是随机抽取的子集，**不是**完整商品库，也不提供全量导出。

## 本地试查

```bash
# 按商品名称（部分匹配）
python3 examples/lookup.py --name 伊利

# 按商品条码
python3 examples/lookup.py --barcode 6907992527680
```

Node：

```bash
node examples/lookup.mjs --name 伊利
node examples/lookup.mjs --barcode 6907992527680
```

授权 API 的查询形态与上面一致，只是数据换成完整库并持续更新：

```http
GET /v1/products?name=伊利伊刻活泉双桃乌龙茶500ml
GET /v1/products?barcode=6907992527680
```

公开文档只示范「查一条」，不提供列出全部商品的接口。

## 授权 API（完整库）

样本用于联调。若需要：

- 完整商品资料（含进货渠道价）
- 按名称 / 条码查询
- 新上市日用快销品一周内入库
- 不定期更新规格与渠道价

请申请 API 授权（按密钥、按月）。授权范围禁止：批量镜像、二次转售、把查询结果再包装成数据包出售。

> 申请方式：在 Issue 里留下团队简介和对接场景，或通过仓库说明中的联系方式获取测试密钥。
