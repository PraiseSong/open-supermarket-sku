# open-supermarket-sku

一个开源的、免费的，面向商超便利店、批发选品和日用品进货工具的商品库。

- 用**商品名称**查询：商品条码、规格等
- 用**商品条码**反查：商品详情（名称、规格、最新渠道进货价等等）

本仓库**只开源 2000 条商品的基础数据**（名称、条码、规格、分类），满足基本的对接和联调。

需要**全量、更丰富的数据**（进货渠道价、商品图片、定期更新）请**扫码联系**，备注：`开源商品库对接交流`。

这 2000 条开源数据也会**不定期刷新**（抽样会替换、字段会校正），但仍然只覆盖基础字段、不是全量库。

## 开源样本 vs 完整库

| | 开源商品库 | 完整全量商品库（扫码联系 / API 授权） |
|---|---|---|
| 开放范围 | **仅 2000 条**基础数据 | **全量**丰富数据 |
| 商品名称 / 条码 / 规格 / 分类 | ✓ | ✓ |
| 进货渠道价 | ✗ | ✓ |
| 商品图片 | ✗ | ✓ |
| 数据更新 | **不定期刷新**这 2000 条 | **定期更新**全量；新上市日用快销品可一周内入库 |
| 查询方式 | 本地 JSONL | 按名称 / 条码 API 查询，或面谈对接方式 |
| 用途 | 联调、评估字段是否够用 | 进货、选品、模型训练、店长工具、商超便利店竞品分析等生产接入 |
| 如何获取 | Clone 本仓库 | **微信扫码联系** |

## 样本字段

| 字段 | 说明 |
|------|------|
| `name` | 商品名称 |
| `barcode` | 商品条码 |
| `spec` | 规格（数组，可能有多种包装） |
| `category` | 分类（便于浏览样本） |

数据文件：[`data/products.sample.jsonl`](data/products.sample.jsonl)（一行一条 JSON）  
预览 8 条：[`data/products.preview.json`](data/products.preview.json)

这 2000 条是基础字段的随机抽样，**不是**完整商品库，也不提供全量导出。开源清单会不定期刷新，但仍保持约 2000 条、不含渠道价和图片。

## 本地试查

```bash
# 按商品名称（部分匹配）
python3 examples/lookup.py --name 伊利

# 按商品条码
python3 examples/lookup.py --barcode 6907992527680
```

Node：

```bash
node examples/lookup.mjs --name 伊利
node examples/lookup.mjs --barcode 6907992527680
```

授权 API 的查询形态与上面一致，只是数据换成完整库并持续更新：

```http
GET /v1/products?name=伊利伊刻活泉双桃乌龙茶500ml
GET /v1/products?barcode=6907992527680
```

公开文档只示范「查一条」，不提供列出全部商品的接口。
